# Security policy

## Supported versions

Security fixes are made on the `main` branch. Published releases receive fixes when practical; users should move to the latest supported release.

## Report a vulnerability

Please report vulnerabilities privately through [GitHub Private Vulnerability Reporting](https://github.com/ME-Massine/pulsestream/security/advisories/new). Do not open a public issue for an unpatched vulnerability. Include the affected version or commit, steps to reproduce, and any relevant impact.

Maintainers acknowledge reports, assess severity, coordinate a fix, and publish an advisory after a fix is available. If private reporting is unavailable, contact the repository owner through their GitHub profile and ask for a private security contact.
